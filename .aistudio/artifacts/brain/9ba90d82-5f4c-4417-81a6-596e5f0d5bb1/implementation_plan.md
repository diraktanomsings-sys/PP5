# ตราสัญลักษณ์โรงเรียนบ้านคูเมือง (Original School Crest Implementation Plan)

แผนงานปรับเปลี่ยนและติดตั้งตราสัญลักษณ์ประจำโรงเรียนบ้านคูเมืองด้วยไฟล์ภาพต้นฉบับจริง โดยไม่มีการดัดแปลง ต่อเติม หรือสร้างใหม่ใดๆ ทั้งสิ้น พร้อมการปรับแต่งการแสดงผลให้คมชัดและรักษาสัดส่วนแท้จริงในทุกหน้าของระบบ

## User Review & Critical Decisions

> [!IMPORTANT]
> **สรุปการตัดสินใจตามความต้องการของผู้ใช้งาน:**
> 1. **การใช้ภาพต้นฉบับแท้จริง (Original Source)**: นำไฟล์ภาพตราโรงเรียนต้นฉบับจริง (`school_logo_khumuang_1791401879569.jpg` ซึ่งมีดอกบัว รัศมีดวงอาทิตย์ ต้นไม้ หลังคาจั่ว โล่สีน้ำเงิน-ทอง ค.ม. และแถบชื่อ "โรงเรียนบ้านคูเมือง") มาใช้งานโดยตรง **ห้าม** ใช้ภาพที่ AI เจนเนอเรตขึ้นมาใหม่ หรือต่อเติมซุ้มเรือนยอด ยอดเจดีย์ ลายไทย หรือดัดแปลงองค์ประกอบใดๆ
> 2. **รักษาสัดส่วนภาพและความคมชัด (No Distortion & Aspect Ratio Preservation)**: ใช้การแสดงผลแบบ `object-contain` เพื่อให้ตราโรงเรียนรักษาสัดส่วนแนวตั้ง (Aspect Ratio 896:1200) ไม่ถูกยืด บีบ หรือครอบตัด
> 3. **อัปเดตครบทุกจุดในระบบและล้างการแคช (Cache Busting)**: อัปเดต `schoolLogo.ts`, `public/school_logo.png`, `public/favicon.png`, `index.html` พร้อมทั้งใส่ Cache Versioning เพื่อให้เบราว์เซอร์แสดงภาพใหม่ทันที ไม่ติดภาพเก่าในหน่วยความจำแคช

---

## 1. Overview & Core Concept

- **วัตถุประสงค์หลัก**: แทนที่ตราโรงเรียนจำลองและตราที่ถูกดัดแปลงทั้งหมดในระบบ ปพ.5 ดิจิทัล (โรงเรียนบ้านคูเมือง สังกัด สพป.สิงห์บุรี) ด้วยตราสัญลักษณ์ของจริงที่ถูกต้องตามอัตลักษณ์สถานศึกษา
- **กลุ่มผู้ใช้งาน**: ผู้บริหาร (ผอ.), ครูผู้สอน, หัวหน้ากลุ่มสาระฯ, งานทะเบียนวัดผล และผู้ดูแลระบบ ที่เปิดใช้งานระบบ ปพ.5 ดิจิทัลและพิมพ์เอกสารราชการ
- **คุณค่าที่ได้รับ**: เอกสาร ปพ.5 ดิจิทัล, ใบประกาศรับรอง Hash, หน้าต่างล็อกอิน และหัวระบบจะมีตราสัญลักษณ์ถูกต้องตามระเบียบราชการ 100%

## 2. User Experience & Visual Design

- **หน้าเข้าสู่ระบบ (Login & Role Selection)**:
  - แสดงตราสัญลักษณ์แท้จริงขนาดชัดเจนกลางหน้าจอ พื้นหลังโปร่งสะอาด ไม่ใส่กรอบหนาหรือแสงเงาที่บดบังรายละเอียด
  - มีชื่อสถานศึกษา "โรงเรียนบ้านคูเมือง" สังกัดสำนักงานเขตพื้นที่การศึกษาประถมศึกษาสิงห์บุรี กำกับอย่างเป็นทางการ
- **แถบนำทางด้านบนและแถบด้านข้าง (TopNavbar & Sidebar)**:
  - ตราสัญลักษณ์ย่อขนาดอย่างพอดีในสัดส่วนดั้งเดิม ควบคู่กับชื่อระบบ "ระบบบันทึกและอนุมัติ ปพ.5 ออนไลน์"
- **เอกสาร ปพ.5 และโมดอลรับรองดิจิทัล (Grade Sheet & Certificate Modal)**:
  - ส่วนหัวของเอกสาร ปพ.5 แสดงตราโรงเรียนแท้จริงอย่างสง่างาม คมชัด รองรับการสั่งพิมพ์และการตรวจรับรองจาก ผอ.
- **ไอคอนแท็บเบราว์เซอร์ (Favicon)**:
  - ไอคอน Favicon ของเว็บไซต์จะแสดงตราสัญลักษณ์จริง ไม่แสดงไอคอนจำลองเดิม

## 3. Key Product Decisions & Trade-Offs

- **การจัดการไฟล์ภาพต้นฉบับ**:
  - *แนวทางที่เลือก*: ผูก `src/assets/schoolLogo.ts` เข้ากับไฟล์ต้นฉบับแท้จริงของโรงเรียนโดยตรง พร้อมสร้างไฟล์ความละเอียดสูงสำหรับ `public/school_logo.png`, `public/school_logo.jpg` และ `public/favicon.png` จากต้นฉบับแท้ เพื่อให้ Vite Bundle ได้ asset hash ที่ถูกต้อง และเบราว์เซอร์ไม่แสดงภาพค้างจากแคช
  - *เหตุผล*: ป้องกันปัญหาเบราว์เซอร์แคชภาพเดิม และรับประกันว่าทุกคอมโพเนนต์ที่เรียกใช้ `schoolLogo` จะได้ภาพเดียวกันทั้งหมดทันที
- **การจัดสัดส่วนการแสดงผล (CSS Object-Contain)**:
  - *แนวทางที่เลือก*: กำหนด `object-contain` และหลีกเลี่ยงการบังคับ `w == h` ที่บีบอัดรูปภาพ
  - *เหตุผล*: ภาพตราโรงเรียนต้นฉบับมีสัดส่วนแนวตั้งสง่างาม การใช้ `object-contain` จะคงความสมบูรณ์ของภาพไว้ครบถ้วนทุกรายละเอียด

### แผนการดำเนินการเมื่อได้รับอนุมัติ:
1. **อัปเดต Module Asset**: แก้ไข `src/assets/schoolLogo.ts` ให้ import ไฟล์ตราโรงเรียนต้นฉบับจริง
2. **สร้าง Public Static Assets**: แปลงและคัดลอกไฟล์ต้นฉบับจริงไปยัง `public/school_logo.png`, `public/school_logo.jpg` และ `public/favicon.png`
3. **ปรับปรุงการแสดงผลในคอมโพเนนต์**: ตรวจสอบ `LoginView.tsx`, `RoleSelectionView.tsx`, `TopNavbar.tsx`, `Sidebar.tsx`, `Header.tsx`, `GradeSheetSimulator.tsx` และ `CertificateHashModal.tsx` ให้ใช้ `object-contain` ไร้การบิดเบือน
4. **Cache Busting**: อัปเดต timestamp query param ใน `index.html` เพื่อการันตีว่าเบราว์เซอร์จะดึงภาพใหม่ทันที
5. **ทดสอบความถูกต้อง**: รัน `compile_applet` และ `lint_applet` ตรวจสอบความสมบูรณ์ 100%
